### Iterations 1–3: Foundation

- **0001** The Cartographer's Confession [fiction, 4.9]: Mapmaker's fraudulent town calcifies into reality. Masterful speculative fiction; set the quality bar.
- **0002** Drift Signal [music, 4.4]: Harmonic drone documenting its own dissolution. Required revision — first version had no actual audio decay mechanics. Exposed Web Audio testing gap.
- **0003** Mass [poetry, 4.3]: Liturgical anaphora applied to scientific chronicle. Formal experiment that accumulated devotional force through structure.

### Iterations 4–5: Infrastructure Failures

Both failed with `Cannot read properties of undefined`. Same root cause — pipeline bug, not artifact quality issue. No artifacts produced.

### Iterations 6–9: Breakout Cluster

- **0004** Syntax Error at Line 47 [code-game, 4.9]: Debugging game where every mechanical choice is emotional. Portfolio's first code-game and first great one.
- **0005** Unfollow [experiment, 4.7]: Writing surface enacting loss through interface degradation. First experiment; established "user as complicit agent" pattern.
- **0006** The Resignation Engine [code-tool, 4.7]: Corporate formality as pressure cooker for accidental disclosure. First code-tool; darkly comic.
- **0007** Tender / Mercies [essay, 5.0]: Forensic annotation of a fabricated one-star hospice review. First perfect score; form-as-content thesis executed flawlessly.

### Iterations 10–12: Consolidation and Truncation Troubles

- **0008** The Incident at Location 44.789, -93.204 [fiction, 4.3]: Municipal incident report as procedural horror. Proficient but unsurprising — "safe choices made to avoid failure."
- **0009** Signals from the Combiner [code-art, 4.7]: Markov chain text collision as SVG seismograph. First code-art; required revision due to truncation. Meticulous engineering.
- Iteration 12: Another `undefined` infrastructure failure.
- **0010** Etymon [code-tool, 4.7]: Etymology dataset with 40 words rendered as git-blame. The notes ("mortgage = death pledge," "silly fell from blessed to frivolous") transcend reference material.

### Iterations 13–15: Peak Form

- **0011** Mise en Abyme [code-game, 4.9]: Text adventure where parser is narrator and prisoner. Stress system, mishearing mechanics, contradiction detection — every system serves meaning. Joined Syntax Error as portfolio's second great game.
- **0012** Lacuna [experiment, 5.0]: Text erasure shaped by invisible love letter. Accelerating timer, found poem ending, user's choices becoming content. Portfolio's most emotionally sophisticated artifact; second perfect score.

### Key Decisions

- **Approved but not activated:** The Registry (worldbuilding, museum catalog horror) and Apocrypha (worldbuilding, scholarly disagreement as method). Both approved at gate1 multiple times. Neither picked up as active project.
- **Approved, awaiting creation:** Failure Modes (poetry, structures embodying failure modes), The Consultation (fiction, clinical documentation as horror).
- **Rejected:** Soft Meridian (poem already written itself), Owl in Concrete (constraint that constrains), Signal Drift (experience in search of user).
- **Recurring gate1 reasoning:** Proposals rejected when the pitch contains the entire artifact, leaving no room for surprise in the making. Proposals approved when the form IS the argument.
